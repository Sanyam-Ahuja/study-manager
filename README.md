# 🚀 Featured Project — Study Manager

**A distraction-free lecture watching web app built to help students stay focused.**

**Short description**  
Study Manager helps students watch lecture playlists without distractions, track study time, and maintain focus. It’s hosted 24/7 and includes a simple registration and login flow so users can save preferences and playlists.

---

## 🎯 Highlights
- ✅ Supports YouTube playlists for seamless study sessions  
- ✅ 24/7 hosted on a server (always-on access)  
- ✅ Simple registration & login system  
- ⚠️ **Note:** Login/Registration may take **up to 1 minute** due to DB latency — **please click once and wait.**

---

## 🧰 Tech stack
- **Frontend:** React (HTML, CSS, JavaScript)  
- **Database:** Supabase DB  
- **Hosting:** 24/7 server Vercel And Render
---

## 🚀 Quick start

https://study-manager-eight.vercel.app/


## ⚠️ Known issues & guidance
- **Long login/registration times:**  
  The app may experience **long login/registration times (up to ~1 minute)** when the database is under load or the connection pool is cold. This is a known issue caused by DB latency and cold starts on small hosting plans.
  - **User-facing note:** Please click the login/register button **only once** and wait up to **1 minute** for the server to respond.
